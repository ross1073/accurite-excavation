## Findings by Severity

### HIGH (3 issues)

#### 1. No sticky mobile CTA
- **Category:** Click-to-Call & CTA
- **Location:** Site-wide
- **Finding:** No fixed-position "Call Now" button for mobile users. Visitors scrolling on mobile have no persistent call option.
- **Fix:** Add a fixed-position call button visible only on mobile:
  ```html
  <div class="sticky-cta lg:hidden fixed bottom-0 left-0 right-0 z-50">
    <a href="tel:+18018146975" class="btn" data-source="sticky-cta">
      Call (801) 814-6975
    </a>
  </div>
  ```

#### 2. Brand name capitalization "Accurite" on 11 location pages
- **Category:** Cross-Page Consistency
- **Location:** src/content/locations/ — eden.md, perry.md, willard.md, farr-west.md, riverdale.md, huntsville.md, west-haven.md, harrisville.md, north-ogden.md, south-ogden.md, pleasant-view.md

#### 3. Inconsistent title brand format
- **Category:** Cross-Page Consistency
- **Location:** Multiple location pages
- **Finding:** Some titles use "| AccuRite Excavation" while others use "| AccuRite Excavation & Hauling". The shortName is "AccuRite Excavation" — should be consistent.
- **Fix:** Standardize all titles to use "| AccuRite Excavation" as the brand suffix.
