# 2026-06-02 — Diagnosed "no clicks" in AccuRite rank report; fixed command-center generator

## What we did
- Diagnosed why the AccuRite rank report (rnr-command-center.netlify.app/ranks/accuriteexcavation-com) showed "Total Clicks: 4" despite ~3,294 impressions: GSC's `query` dimension (used for per-keyword data) is heavily anonymized and capped at top-50 queries per daily run, so it badly undercounts real clicks; the Page Performance table (GSC `page` dimension) shows accurate clicks (~47–100).
- Found a second bug: the Page Performance table showed the homepage `/` duplicated because GSC reports http/https and www variants as separate rows with no dedup.
- Fixed both issues in `rank_report.py` (3sm_code repo, commit a050365 on main): (1) "Total Clicks" headline now sums GSC page-level clicks with fallback to keyword sum; (2) Page Performance deduplicates rows by URL path, summing impressions/clicks, recomputing CTR, and impression-weighting avg position.
