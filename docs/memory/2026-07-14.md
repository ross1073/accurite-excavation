### The production incident (2026-07-14)

**What happened:** The SessionEnd hook for a prior mini-session fired mid-session, auto-committed staged `git rm` deletions of two AI images (committed as `54053d2` under "docs(memory): auto-commit daily note") and pushed them to `origin/main`. But `about.astro` and `index.astro` still imported those deleted files. Astro couldn't resolve the imports. Netlify build state `54053d2`: **error**. No visible customer outage — the live site served the last good deploy — but no new deploy could succeed until repaired.

**Root cause:** The hook ran `git add docs/memory/` (correctly scoped) then `git commit` with no pathspec. A bare `git commit` commits the entire index, not just what the hook staged. Anything already staged at hook-fire time was swept in and pushed.

**Fix to hook:** `git commit` → `git commit -- docs/memory/` (pathspec-limited). Proven in an isolated test: staged site files are now left untouched.
