## Gotchas surfaced
- Pasted-in-chat images are NOT on disk — there's no file path to copy. The macOS `osascript … (the clipboard as «class PNGf»)` trick can write a clipboard image to a file, but on first try it grabbed the WRONG image (an unrelated, sensitive financial doc that happened to be on the clipboard). Caught it only by `Read`-ing the saved PNG, then deleted it. Always verify image content by eye before trusting/committing. The real letter was ultimately pulled from `~/Downloads/HHI SAFETY LETTER.png`.
