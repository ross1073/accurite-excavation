### Gotchas surfaced
- CPC is the most reliable available signal for real hire-intent vs. DIY/informational in this dataset — e.g. `french drain` ($2.33 CPC, nobody's hiring) vs `french drain installation near me` ($19.91 CPC, that click is a real job lead).
- Google returns the same underlying query under multiple phrasings with identical volume/CPC figures (e.g. `demolition contractor` / `demolish contractor` / `contractor demolition`) — naive summing across variants double-counts demand.
- `sewer tank installation` is Google's alias for SEPTIC tank installation (same $60.70 CPC as septic terms) — it was mislabeled into the sewer/water-line bucket until caught; watch for this on any future septic-adjacent pull.
- "Winter excavation" as a standalone search topic essentially does not exist in this dataset — the whole lane returned only 1 keyword above 20/mo (`frost line depth utah`, 30/mo, peaks in March). Don't write "we dig in frozen ground" content expecting search traffic to support it.
- Demolition genuinely peaks in winter (`demolition contractors near me`, $20.33 CPC, Winter 400/Spring 180/Summer 130/Fall 70) — real, corroborated seasonal signal, unlike the sewer spike above.
